Was ist HTML

HTML steht fuer Hyper Text Markup Language und ist eine Auszeichnungssprache fuer Webseiten.

Mit HTML können Struktur und Inhalt von Webseiten definiert werden. Es besteht aus einer Reihe von Elementen, die durch Tags gekennzeichnet sind.

HTML ist die Grundlage des World Wide Web und wird von allen Webbrowsern unterstützt.

Zusammen mit CSS und JavaScript bildet HTML die Kerntechnologie für die Erstellung von Webseiten und Webanwendungen.

HTML Elemente

Ein HTML-Element besteht aus einem Starttag, Inhalt und einem Endtag:

<element>Inhalt</element>

Das Starttag besteht aus einem spitzen Klammer auf <, dem Elementnamen und einem spitzen Klammer zu >.

Der Inhalt ist der Text oder die Medien, die innerhalb des Elements angezeigt werden.

Das Endtag besteht aus einem spitzen Klammer auf </, dem Elementnamen und einem spitzen Klammer zu >.

HTML Tags

HTML-Tags sind Schlüsselwörter, die in spitzen Klammern < und > geschrieben werden und den Browser anweisen, wie der Inhalt angezeigt werden soll.

Einige häufig verwendete HTML-Tags sind:

  • <h1> - <h6>: Überschriften
  • <p>: Absätze
  • <a>: Links
  • <img>: Bilder
  • <ul>: Ungeordnete Listen
  • <ol>: Geordnete Listen
  • <li>: Listenelemente
  • <table>: Tabellen
  • <tr>: Tabellenzeile
  • <td>: Tabellendaten

HTML Attribute

HTML-Attribute werden in den Starttags von HTML-Elementen verwendet und geben zusätzliche Informationen über das Element.

Einige häufig verwendete HTML-Attribute sind:

  • href: Der Link-URL für <a> Elemente
  • src: Die Quell-URL für <img> Elemente
  • alt: Der Alternativtext für <img> Elemente
  • style: CSS-Stilregeln für das Element
  • id: Ein eindeutiger Bezeichner für das Element
  • class: Eine Klassenzuweisung für das Element
  • title: Der Titel des Elements

HTML Dokumentstruktur

Ein HTML-Dokument besteht aus einem Kopfteil und einem Rumpfteil:

  • Der Kopfteil enthält Metadaten über das Dokument, wie den Titel und die Zeichencodierung.
  • Der Rumpfteil enthält den Inhalt der Webseite, wie Überschriften, Absätze und Medien.

Ein einfaches HTML-Dokument sieht so aus:

        
            <!DOCTYPE html>
            <html>
            <head>
            <title>Titel der Webseite</title>
            </head>
            <body>
            <h1>Überschrift</h1>
            <p>Absatz</p>
            </body>
            </html>
