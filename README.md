# 🏫 Schulprojekt:

Ein Webentwicklungsprojekt, das im Rahmen des Informatikunterrichts entstanden ist. Die Website wurde komplett eigenständig mit den grundlegenden Webtechnologien (HTML, CSS und JavaScript) umgesetzt.

## 🚀 Projektbeschreibung
Ziel des Projekts war es, eine funktionale Website zu erstellen, die mit einer Grundbasis aufgebaut werden soll. Dabei lag der Fokus auf einem sauberen Code-Aufbau, responsivem Design für Mobilgeräte und interaktiven Elementen durch JavaScript.

## 🛠️ Verwendete Technologien
* **HTML5:** Strukturierung der Inhalte und semantischer Aufbau.
* **CSS3:** Modernes Styling, Layouts (z.B. Flexbox/Grid) und responsive Anpassungen.
* **JavaScript (Vanilla):** Dynamische Inhalte, Event-Handling und Interaktivität.
